# 📝 To-Do List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. It helps users organize daily tasks, track completed work, and stay productive.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- 🧹 Clear all tasks at once
- 💾 Save tasks using browser Local Storage
- 📊 Display remaining task count
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Task management and functionality
- **Local Storage** — Save tasks in the browser

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in the same folder.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.

## 💡 How to Use

1. Enter a task in the input field.
2. Click **Add +** or press Enter.
3. Tick the checkbox when a task is completed.
4. Click **Delete** to remove a task.
5. Use **Clear All** to remove all tasks.

Your tasks are saved in browser Local Storage and remain available after refreshing the page in the same browser.

## 🎯 Project Objective

This project was created to practice front-end web development, DOM manipulation, event handling, and browser Local Storage.
